# PixelVault

Site Front-End de uma loja de jogos digitais, desenvolvido como trabalho da disciplina de Design Profissional (UNICID). O site reúne HTML5 semântico, formulários com validação nativa, CSS3 responsivo, recurso multimídia, navegação entre páginas, documentação e versionamento com Git e GitHub.

**Público-alvo:** jogadores que querem conhecer, comparar e escolher jogos.

## Páginas

| Arquivo | Descrição |
|---|---|
| `index.html` | Página principal, com destaques, novidades e trilha sonora |
| `catalogo.html` | Catálogo de jogos com filtro por gênero |
| `categorias.html` | Gêneros de jogos |
| `jogo.html` | Detalhes de um jogo |
| `lancamentos.html` | Jogos novos e próximos lançamentos |
| `ranking.html` | Jogos mais bem avaliados |
| `noticias.html` | Notícias do mundo dos games |
| `sobre.html` | Identidade e equipe |
| `contato.html` | Informações e formulário de contato |
| `orcamento.html` | Pesquisa comparativa de domínio e hospedagem |
| `login.html` | Login e cadastro (somente layout) |

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

### Publicar no GitHub Pages

1. No repositório, abra **Settings > Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`, e salve.
